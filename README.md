# YetAnotherDiscogsLastFMIntegrationTool

For now, this is all just a proof of concept, development will be done whenever I get inspired to work on this.

## What are the goals with this project?

I want to create a desktop tool that lets users scrobble releases from Discogs, similar to many other already existing apps.

## Why create another Vinyl Scrobbler?

No shade to the people who have already made tools like these, but the idea of charging people to scrobble more than just a few albums per month is something I do not like. I feel like having an offline tool like this can erase the need of a monthly fee for basic usage, hence why I'm doing a Python app instead of a web-based thing.

Also, the already existing options lack some features that I would much appreciate, like the option to edit what is going to be scrobbled (VinylScrobbler for example does not properly register some characters, making for broken scrobbles).
